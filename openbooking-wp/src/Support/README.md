# Support

Utilidades transversales usadas por todos los modulos del plugin.

- `Container.php` → Contenedor de inversion de control.
- `Setting_Keys.php` → Constantes para todas las claves de opciones (obwp_*).
- `Option_Keys.php` → Constantes para opciones internas del plugin.
- `Cron_Hook_Keys.php` → Constantes para hooks de cron.
- `Cached_Options.php` → Cache de opciones WP para reducir consultas.
- `Timezone_Helper.php` → Conversion de zonas horarias.
- `Crypto.php` → Cifrado de datos sensibles.
- `Request_Context.php` → Contexto de la peticion HTTP actual.
